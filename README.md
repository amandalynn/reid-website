# Reid Watts - Gaming Portfolio

A futuristic, neon-themed single-page website for Reid Watts, featuring stunning glow effects, animations, and a gamer-cool aesthetic.

## 🎮 Features

- **Neon Glow Effects**: Electric aqua and purple glowing text with custom shadows
- **Smooth Animations**: Framer Motion powered transitions and interactions
- **Starfield Background**: Animated twinkling stars
- **Interactive Elements**: "Press Start" button with Level Up animation
- **Floating Game Icons**: Animated emoji decorations
- **Particle Effects**: Explosive particles on button click
- **Responsive Design**: Works beautifully on mobile and desktop
- **Gaming Font**: Custom Orbitron font from Google Fonts

## 🚀 Tech Stack

- **React 18** with TypeScript
- **Vite** for blazing fast builds
- **TailwindCSS** for utility-first styling
- **Framer Motion** for smooth animations
- **Custom CSS** for glow effects and gradients

## 📦 Installation

```bash
npm install
```

## 🎯 Run Development Server

```bash
npm run dev
```

Visit `http://localhost:5173` to see the site in action!

## 🏗️ Build for Production

```bash
npm run build
```

## 👾 Customization

### Colors
Edit `tailwind.config.js` to change the color scheme:
- `primary`: Electric aqua glow color
- `secondary`: Dark background color
- `accent`: Purple glow color

### Animations
Modify animation speeds in `tailwind.config.js` under the `animation` section.

### Content
Update text and emojis in `src/components/Hero.tsx`.
